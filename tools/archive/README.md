# tools/archive/

Архив устаревших тестов. Эти тесты не проходят в текущем состоянии проекта
(требуют зависимостей, окружения или функциональности, которая была переработана).

Перенесены из tools/ и корня проекта в рамках M-04 (гигиена репозитория).
Не запускаются в CI. Для восстановления — перенести обратно и починить.

## test_full_flow*.py (из корня)
Устаревшие integration-тесты полного цикла. Заменены тестами в tests/.

## test_v6*.py (из tools/)
Версионные тесты, привязанные к конкретным версиям функциональности.
Большинство требует специфического окружения (playwright, pyautogui, LM Studio).
